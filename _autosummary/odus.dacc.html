odus.dacc¶

Data access: stores and accessors over the survey data.

Defines the py2store-based stores (DfStore, VarSetCountsStore, PotStore) and the Dacc facade that give easy access to the prepared trajectory dataframes, their count tables, and the corresponding potentials.

odus.dacc.prep_trajectory_df(df, *, source=None, non_binary='warn', duplicates='merge')[source]¶

Clean a trajectory DataFrame (index: ages, columns: variables).

  • Columns named like a section title of the survey sheet (NON_VARIABLE_LABELS of odus.raw_data_diagnosis, e.g. “Select States below”) are dropped.

  • duplicates: what to do with variables appearing more than once (e.g. a state lived in during two periods, entered as two rows), names compared ignoring case and extra spaces. "merge": one column (with the first name), holding at each age the first non-zero value of the duplicates; "keep": leave them; "raise": raise a ValueError.

  • non_binary: what to do with values other than 0 and 1. "warn": set them to 1 and say which (variable, ages, values); "binarize": set them to 1 silently; "keep": leave them; "raise": raise a ValueError.

source (e.g. the file name) is only used in messages.

>>> df = pd.DataFrame(
...     [[1, 0, 0, 0], [0, 0, 1, 2]],
...     columns=['GA', 'NJ', 'NJ', 'Select States below'],
...     index=pd.Index([20, 21], name='age'),
... )
>>> out = prep_trajectory_df(df)
>>> out.columns.tolist(), out.values.tolist()
(['GA', 'NJ'], [[1, 0], [0, 1]])
