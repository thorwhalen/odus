odus.raw_formats¶

Reading raw survey data, of several formats, into trajectories.

A trajectory is a DataFrame with one row per age (the index, named age) and one column per variable, holding the respondent’s value of that variable at that age (typically 0 or 1). Its attrs[YEAR_OF_AGE] maps each age to its year.

What varies from one data source to another is configuration, not code:

  • The file format: read_raw_table picks a reader in TABLE_READERS by file extension (.xlsx, .xls, .csv, .tsv). Pass readers= with more entries to read other formats.

  • The layout of a “wide” table (variables as rows, ages as columns, as in the ODUS spreadsheets): a SurveyLayout says where the years, the ages, the variable names and the values are. trajectory_from_table reads one.

  • “Long” (tidy) tables, with one row per (age, variable, value), are read by trajectory_from_long.

>>> raw = pd.DataFrame([
...     [None, 'ID', 'X01', None],
...     [0, 'YEAR', 2000, 2001],
...     [1, 'AGE', 20, 21],
...     [3, 'HEROIN', 0, 1],
...     [4, 'WORK', 1, 1],
... ])
>>> t = trajectory_from_table(raw)
>>> t.index.tolist(), t.columns.tolist(), t.values.tolist()
([20, 21], ['HEROIN', 'WORK'], [[0, 1], [1, 1]])
>>> t.attrs[YEAR_OF_AGE]
{20: 2000, 21: 2001}

Bases: object

Where things are in a “wide” survey table (0-based row and column numbers).

Parameters:

  • year_row (int | None) – The row holding the years (None if there’s none).

  • age_row (int) – The row holding the ages.

  • data_start_row (int) – The first row of variables.

  • label_col (int | None) – The column holding the variable names. None: the column with the most text from data_start_row on. The ages and values are in the columns after it.

  • section_titles (tuple) – Labels of rows that title a section rather than name a variable (compared ignoring case and extra spaces). Those rows are skipped.

  • empty_value (float | None) – The value of an empty data cell. None: an empty cell is an error.

Parameters:

  • age – The names of its columns holding those.

  • variable – The names of its columns holding those.

  • value – The names of its columns holding those.

  • year – The name of the column holding the year (optional).

  • fill_value – The value of (age, variable) pairs absent from the table.

>>> long = pd.DataFrame({
...     'age': [20, 21, 21], 'year': [2000, 2001, 2001],
...     'variable': ['HEROIN', 'HEROIN', 'WORK'], 'value': [0, 1, 1],
... })
>>> t = trajectory_from_long(long, year='year')
>>> t.values.tolist(), t.attrs[YEAR_OF_AGE]
([[0, 0], [1, 1]], {20: 2000, 21: 2001})
